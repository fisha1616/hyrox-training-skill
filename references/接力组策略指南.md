# HYROX接力组策略指南

## 四人接力组基础规则

- **总距离**：8km跑 + 8个功能站（与单人/双人组相同）
- **分工方式**：4人分跑跑步和功能站，每人负责2km跑 + 2个功能站
- **换人规则**：每完成1km跑 + 1个功能站后换下一位队友
- **完赛标准**：全队完成所有项目

---

## 组队建议

### 队友选择策略

**新手团队建议：找1-2个更强的队友**

| 队员配置 | 原因 |
|----------|------|
| 1-2个对负重/技术站更有把握的队友 | 覆盖团队中无人明确胜任的站点（如推雪橇、弓步走、墙球） |
| 其余队员 | 在安全范围内承担明确能力项与可培养项，保持每人两站的体验与责任平衡 |

**为什么这样配置？**
- 高难度站点需要相应力量或技术基础，必须提前实测
- 每人固定负责两个功能站，不存在由一名“强者”临场多做几个站的分法
- 站点难度高度依赖体型、技术和训练背景，不把拉雪橇、农夫行走或波比跳笼统称为“简单项目”

**避免的情况**：
- ❌ 4个都是新手 → 高难度站点无人能扛，可能无法完赛
- ❌ 水平差距太大+没有沟通 → 强者抱怨队友慢，体验差

### 陌生人组队（小红书/网络组队）

**最重要的不是合练，而是能在交接区认出队友**

| 识别方法 | 建议 |
|----------|------|
| **统一标识** | 同样颜色的护腕、发带、队服、帽子 |
| **提前沟通** | 确认每个人的站点分工、交接顺序 |
| **赛前见面** | 至少在签到时见一面，认脸+确认分工 |

**交接区识别清单**：
1. 约定统一的识别物（如：蓝色护腕）
2. 记住队友的长相/特征
3. 确认交接顺序（谁→谁→谁→谁）
4. 留下联系方式（微信/电话）

**陌生人组队注意事项**：
- 提前确认队友是否靠谱（是否真的参赛）
- 确认队友的训练水平和站点偏好
- 明确分工，避免临时争抢/推诿
- 合练不是必须，但赛前沟通是必须

## 个性化分工决策流程

### 先分四类信息

生成方案前，把每位队员的描述拆成四类，禁止混为一谈：

| 类型 | 示例 | 处理方式 |
|------|------|----------|
| **硬禁项** | “完全不行”“不能做”“伤病会不适” | 正式方案必须排除 |
| **明确能力** | “擅长”“可以”“能做” | 优先匹配，但不必把两个最擅长项目都给同一人 |
| **可培养项** | “可以加练”“没人我可以试试” | 可作为挑战项，标注需实测 |
| **承担意愿** | “想多分担难项”“快乐完赛但别过度照顾” | 与安全约束同等纳入，不得忽略 |

### 按顺序求解

1. **锁定比赛固定站序**：滑雪机 → 推雪橇 → 拉雪橇 → 波比跳远 → 划船机 → 农夫行走 → 负重箭步 → 墙球。
2. **排除硬禁项**：伤病和明确不能做的动作不进入正式方案。
3. **识别结构性缺口**：找出无人明确胜任的站点，例如全队无人会墙球；先向团队说明，不要静默塞给某人。
4. **分配挑战与优势**：优先让每人获得“1个明确能力项 + 1个可承受挑战项”；这不是绝对公式，但比单纯按最擅长匹配更能兼顾公平和体验。
5. **尊重承担意愿**：主动要求多承担的队员，可在其“能做/可培养”范围内增加负重或技术难度；不要用两个舒适项敷衍。
6. **保护但不弱化伤病队员**：仅避开风险动作；如果其能安全完成拉雪橇、农夫行走等负重站，可以正常承担，不要自动安排两个器械站。
7. **检查间隔**：按用户口径执行。用户说“间隔2个以上”时，两站编号差必须 ≥3；默认仅建议间隔2个最佳。
8. **做公平性复核**：检查是否有人被无依据地安排两个明显轻松项、两项均为短板，或承担了团队唯一缺口却未被说明。
9. **输出待验证项**：把墙球、负重箭步等无人明确胜任的分配标为“需标准规格实测”，并说明切换条件。

### 禁止的决策捷径

- ❌ 只按“谁最擅长”最大化效率，忽略队员想承担挑战的意愿。
- ❌ 因一处伤病限制，就把该队员整体视为弱者或只给最简单项目。
- ❌ 把“可以试试”写成“已经胜任”。
- ❌ 把明确禁项放进备选方案，却不征得本人同意。
- ❌ 用“照顾”“兜底”“最简单”等措辞给队员做价值排序；除非用户主动要求难度评价。
- ❌ 用户只要图表时，擅自突出某个队员或添加带倾向性的评价。

### 输出模板

1. 先列固定八站顺序与负责人。
2. 再按人汇总两个站点。
3. 明确写出间隔校验结果。
4. 单列“待实测/风险项”，不要混在既定分工里。
5. 若输出图表，为四人使用相同尺寸、边框和文字权重；颜色只用于区分身份。

## 站点分配核心策略

### 策略一：按体型分配

| 站点 | 适合体型 | 原因 |
|------|----------|------|
| 滑雪机（SkiErg） | 身高腿长 | 拉杆行程长，效率更高 |

| 站点 | 所需能力 | 适合人群 |

| 推雪橇 | 腿部力量+核心稳定 | 力量训练者 |
| 拉雪橇 | 后链力量+握力 | 硬拉强者 |
| 墙球 | 肩部力量+协调性 | 排球/篮球背景 |
| 波比跳 | 爆发力+心肺耐力 | 高强度训练者 |
| 弓步走 | 腿部耐力+平衡 | 跑步背景 |
| 农夫行走 | 握力+核心稳定 | 力量训练者 |

## 出站顺序排序原则

### 核心原则：避免项目连续

**为什么重要？**
- 同一人连续项目会导致疲劳积累，影响后续表现
- 中间间隔可以让队员恢复体力、调整状态
- 团队整体节奏更均衡，减少"短板效应"

### 排序规则

| 规则 | 优先级 | 说明 |
|------|--------|------|
| ❌ 禁止连续 | 最高 | 同一人不能连续负责两个项目 |
| ⚠️ 间隔至少1个 | 高 | 同一人的两个项目之间至少隔1个项目 |
| ✅ 间隔2个最佳 | 推荐 | 同一人的两个项目之间最好隔2个项目（但不绝对） |

### 正确示例

| 顺序 | 站点 | 负责队员 | 说明 |
|------|------|----------|------|
| 1 | 滑雪机 | 板栗 | ✅ |
| 2 | 推雪橇 | 芒果 | ✅ |
| 3 | 拉雪橇 | Lumos | ✅ 与芒果隔开 |
| 4 | 波比跳远 | 板栗 | ✅ 与第1项隔2个 |
| 5 | 划船机 | Marco | ✅ |
| 6 | 农夫行走 | 芒果 | ✅ 与第2项隔3个 |
| 7 | 弓步走 | Lumos | ✅ 与第3项隔3个 |
| 8 | 墙球 | Marco | ✅ 与第5项隔2个 |

### 错误示例（需避免）

| 顺序 | 站点 | 负责队员 | 问题 |
|------|------|----------|------|
| 1 | 滑雪机 | 板栗 | - |
| 2 | 推雪橇 | 芒果 | - |
| 3 | 拉雪橇 | 芒果 | ❌ 连续项目，体力无法恢复 |
| 4 | 波比跳远 | Lumos | - |
| 5 | 划船机 | 板栗 | - |
| 6 | 农夫行走 | Marco | - |
| 7 | 弓步走 | Lumos | - |
| 8 | 墙球 | Marco | ⚠️ 只隔1个，不推荐 |

### 排序优化技巧

1. **先排每个人的第一个项目**：按站点顺序依次分配
2. **再排第二个项目**：确保与第一个项目间隔≥2
3. **检查冲突**：确认无连续、间隔合理
4. **微调**：根据队员专长和体力特点适当调整

## 交接区（TZ）规则详解

### 交接区基本规定

| 规则 | 说明 |
|------|------|
| 进入时机 | 接棒队员**只能在交接前片刻**进入 |
| 禁止逗留 | 此区域内禁止停留等待 |
| 识别责任 | 每支队伍需确保队友按时进入交接区 |

### 交接流程

1. 完成当前站点 → 跑入交接区
2. 与等候的队友**击掌交接**
3. 下一人开始跑步
4. 上一人**立即离开**交接区（避免拥堵）

### 特殊情况：背靠背完成

如果一名队员连续完成2次跑步+2个站点：
- **仍需**在第一个训练站点后跑经交接区
- 目的：确保计时芯片被"识别"
- 未遵守将自动触发处罚

### 交接区违规

| 违规行为 | 后果 |
|----------|------|
| 未按规定跑经交接区 | 自动罚时 |
| 通过"入口"拱门离开站点 | 2分钟罚时 |
| 交接区逗留造成拥堵 | 警告 |

## 26/27 接力赛制更新

> 重量、距离、年龄组与 25/26 一致。接力专属变化详见《核心规则速查.md》一（赛制要点）与《差异清单_26-27接力组规则.md》。

- **分批次出发**：接力组按批次出发，开赛时间展示在手臂上。
- **未满 4 人禁赛**：队伍不足 4 人不得参赛。
- **跑道快速道**：配速 ≥4 分/km 的选手须走快速道（fast lane）。
- **药球终点汇合**：药球投掷站两人需在终点汇合完成。
- **背靠背经交接区**：连续完成 2 次跑步+2 站的队员，仍须在第一个训练站后跑经交接区（确保芯片识别），违者自动罚时。

## 换人区策略

### 换人时机

1. **提前沟通**：倒数第二项完成时，下一位队员做好准备
2. **快速交接**：换人区控制在10-15秒内
3. **情绪管理**：鼓励队友，传递正向能量

### 换人区禁忌

- ❌ 不要在跑步中途换人
- ❌ 不要在功能站未完成时换人
- ❌ 不要在换人区停留过长时间

## 训练建议

### 团队训练重点

1. **个人专项训练**：每人重点练自己负责的站点
2. **跑步训练**：每人至少能舒适完成2km跑
3. **换人演练**：模拟比赛换人流程
4. **团队计时**：定期进行全流程训练

### 推荐训练频率

- 每周2-3次专项训练
- 每周1次团队合练
- 赛前2周进行1-2次完整模拟

## 常见问题

**Q: 可以临时调整站点分配吗？**
A: 可以，但建议赛前确定并充分训练，临时调整可能影响团队配合。

**Q: 如果有队友受伤怎么办？**
A: 接力组无法替补，建议赛前充分准备，避免受伤。如比赛中受伤，团队可以选择DNF（未完赛）或让其他队员分担更多任务。

**Q: 接力组有团队成绩吗？**
A: 有，团队成绩=所有成员完成时间总和，换人时间计入总时间。
