## 一、组别分工规则（最易混淆）

### 双人组（Doubles）

| 项目 | 规则 | 常见误区 |
|------|------|----------|
| **跑步** | 共 8 段×1km，每段两名队员必须**一起跑**；一人跑在同伴前面 → **1 分钟罚时** | ❌ 每人跑 4km；❌ 只需保持在 2 米内 |
| **力量站** | **非常灵活**，每个站点可随意按组数/次数/轮换分工 | ❌ 每人固定做 4 个站 |
| **同时工作** | ❌ 禁止，一次只能一人工作，另一人休息 | - |
| **进出站同步** | 两人必须**同时**进入/离开功能站（未同时到场不能开始，未完成不能离开） | - |
| **不同步后果** | 累计 **>3 次**"未保持同步"罚则 → **Out Of Competition（不排名）** | - |
| **总工作量** | 与单人相同（如划船机总共 1000m） | - |

### 双人组器材传递规则（易犯规）

| 器材 | 传递规则 | 违规后果 |
|------|----------|----------|
| 滑雪机手柄 | ❌ 严禁直接传递 | 罚时 |
| 划船机手柄 | ❌ 严禁互相传递或调节阻力阀 | 罚时 |
| 壶铃 | ✅ 仅允许横向或向后传递，❌ 禁止向前传递 | 罚时（归还错误另计 30 秒） |
| 沙袋 | ✅ 仅允许横向或向后传递，❌ 禁止向前传递 | 罚时 |
| 墙球 | ✅ 仅允许地面交接或手对手传递，❌ 禁止空中传递 | 罚时 |

> ⚠️ 同一时间仅允许一人工作，另一人必须在指定休息区等待

### 接力组（Relay）

| 项目 | 规则 |
|------|------|
| **分工** | 4 人团队，每人完成 **2km 跑 + 2 个功能站** |
| **分组** | 按平均年龄：U40（16-39 岁）/ 40+（40 岁以上） |
| **世锦赛** | ❌ 接力组无世锦赛名额 |
| **赛制要点（26/27）** | 分批次出发；背靠背经交接区（TZ）；未满 4 人禁赛；跑道设快速道（配速 ≥4 分/km 须走快速道）；药球投掷终点汇合 |

## 三、罚则体系（编号 01–24，26/27 新增）

> 25/26 及以前只有笼统罚则；**26/27 起改为「编号罚则 + 每站判罚流程」**，各组通用（个别组别特殊情形见其专项文档）。

### 3.1 通用判罚流程（第 1–7 站，动作/次数类）
- 第 1 次违规（同站）→ **正式警告**
- 第 2 次违规 → 该次重复**无效 + 15 秒罚时**
- 之后每次 → 再加 **15 秒**（不再警告）
- 注：仅 **Race Director（赛事总监）** 有权判 DQ。

### 3.2 罚则总表（01–24，以单人组为基准）

| 编号 | 违规情形 | 罚则 |
|------|----------|------|
| 01 | 漏跑圈 | 3 分（4 圈设定）/ 5 分（3 圈）/ 7 分（2 圈）/ DQ（1 圈设定） |
| 02 | 漏跑或漏站 | DQ |
| 03 | 站点顺序错误 | 首次 3 分，再犯 DQ |
| 04 | 进出拱门（IN/OUT arches）误用 | 每次 2 分 |
| 05 | 功能站进出误用 | 每次 2 分 |
| 06 | 滑雪机脚未踩底座 / 划船机脚未踩踏板就抓手柄 | 每次 15 秒 |
| 07 | 提前离开滑雪机 | DQ（未完成站点，未跑满 1000m） |
| 08 | 提前离开划船机 | DQ（未完成站点，未划满 1000m） |
| 09 | 提前离开药球 | DQ（未完成站点，未投满 100 次） |
| 10 | 漏雪橇道 | DQ（未完成站点） |
| 11 | 波比蛙跳违规 | 每次 15 秒 |
| 12 | 农夫漏圈 | DQ（未完成站点） |
| 13 | 壶铃归还错误 | 30 秒 |
| 14 | 农夫 / 箭步重量错误 | DQ |
| 15 | 箭步后膝未触地 / 未站直 | 每次 15 秒 |
| 16 | 沙袋离肩 | 每次 15 秒 |
| 17 | 起跑隧道逗留（本波次已出发后仍逗留） | 1 分钟 |
| 18 | 防滑粉违规 | 2 分钟 |
| 19 | 外部协助 | 每次 2 分钟 |
| 20 | 未经批准错时出发 | DQ |
| 21 | 比赛中未戴计时芯片 | DNS（未出发） |
| 22 | 吐痰 / 擤鼻 | 2 分钟或 DQ（总监裁定） |
| 23 | 乱扔垃圾 / 急速降温 | 每次 2 分钟 |
| 24 | 不当行为 | 2 分钟或 DQ（总监裁定） |

### 3.3 未完成站点 = DQ（一刀切，新增）
- 8 个站点都必须**完整完成**，任一站点未做完即 **DQ（Incomplete Station）**：不计成绩与排名，但可继续完赛（无最终时间）。
- 典型情形：滑雪机/划船机未跑满 1000m、药球未投满 100 次、雪橇漏道、农夫漏圈、农夫/箭步重量错 → 均判 DQ。

### 3.4 赛后追溯窗口
- 赛事结束后 **48 小时内**仍可追加 / 修正罚则（含 DQ）。

## 五、装备与违禁物品（26/27 扩充）

| 物品 | 说明 |
|------|------|
| 手机* | 严禁；*医疗设备损坏需贴身手机，须赛前经赛事总监批准 |
| 耳机 | 严禁 |
| GoPro / 运动相机 | 严禁 |
| VR 头显 | 严禁（26/27 新增） |
| 头盔** | 严禁（26/27 新增，安全原因） |
| 呼吸装置** | 严禁（26/27 新增） |
| 压缩空气瓶** | 严禁（26/27 新增） |
| 耳塞 | 严禁（26/27 新增） |
| 智能眼镜 / AI 眼镜 | 严禁（含摄像/录音/直播/数据传输/AR 功能的可穿戴眼镜，26/27 新增） |

> ** 出于安全，任何可能危及其他选手的服装/装备不得上赛道（含呼吸装置、压缩空气瓶、头盔；慈善活动穿戴亦不例外）。运动服、负重背心仍允许（不干扰他人即可）。
> 带 * 的医疗设备须赛前联系当地客服对接赛事总监审批。

### ✅ 允许携带
护膝、手套（不含助力握把）、举重腰带、腕带/发带、水袋包、帽子/遮阳帽、小型医疗用品（需能放进口袋，如哮喘吸入器）。

### 拍照解决方案
1. 官方摄影师 Sportograf：赛后约 48 小时可查看下载
2. 观众席拍摄：朋友在观众区帮忙
3. 预约跟拍服务：现场购买

## 六、防滑粉（Chalk）细则（26/27 收紧）

- **仅允许使用赛事提供的防滑粉**；自带粉或把站点粉带走 = **2 分钟罚时**（罚则 18）。
- 防滑粉**仅限雪橇拉（Sled Pull）和农夫行走（Farmers Carry）使用**；在其他任何站点使用 = **2 分钟罚时**。
- 赛前可用粉状或液状粉抹手。
- ⚠️ 注意：是**拉雪橇**（Sled Pull）不是推雪橇；双人/接力组同理仅限拉雪橇 + 农夫行走。

## 七、Out of Ranking（26/27 新增）

- HYROX 有权因环境/场地/安全因素（如湿滑草坪、不安全表面、极端天气）宣布某场或某比赛日为 **「Out of Ranking」**，即不计入世锦赛资格、Elite 15 资格及世界纪录。
- 可由运动总监（Director of Sports）在赛前、赛中或赛后决定。
